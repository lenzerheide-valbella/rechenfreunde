So geht Zahlen-Golf

Dein Ball liegt auf einer Zahl. Das Loch ist eine andere Zahl. Jeder Schläger ist eine Rechnung, zum Beispiel Holz ×2 oder Wedge −4. Triff das Loch genau, mit möglichst wenigen Schlägen.

💦 Landest du im Wasser, gibt es 1 Strafschlag und du schlägst nochmal von vorher. 🚫 Dasselbe gilt, wenn der Ball unter 0 oder über das Platzende fliegt. Ein Chip (:) geht nur, wenn die Teilung ohne Rest aufgeht.

Par ist die Schlagzahl, die ein guter Spieler braucht. Einer weniger ist ein Birdie 🐦, einer mehr ein Bogey. Tipp: Rechne zuerst im Kopf, dann schlag!
